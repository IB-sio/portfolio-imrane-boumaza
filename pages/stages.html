STAGE 1 / DÉVELOPPEMENT WEB

Épicerie du monde

Épicerie de spécialités à Pau

Du 25 mai au 26 juin 2026

Voir le siteTélécharger le dossier photos

Le contexte et la mission

L’Épicerie du monde, au 4 rue Lavoisier à Pau, vend des spécialités de différents pays. Avant le stage, elle était présente sur TikTok mais n’avait pas de site web.

Ma mission : concevoir seul un site vitrine pour présenter le commerce, ses produits et ses informations pratiques, sur ordinateur comme sur téléphone.

DU BESOIN À LA LIVRAISON

Un projet complet

Comprendre la demande, préparer les maquettes, développer, tester et publier. J’ai suivi le projet du début à la fin, avec les retours du gérant.

Les outils du projet

Architecture du site : React, Vite et TypeScript pour l’interface, WordPress comme CMS headless, déploiement sur Netlify.

La création du site, étape par étape

  1. 01 / Figma

    Maquettes sur Figma

    J’ai dessiné les principales pages dans Figma. Les maquettes ont permis de valider leur organisation avec le gérant avant le développement.

  2. 02 / Builder.io

    Premier jet avec Builder.io

    J’ai généré une première version avec Builder.io, puis récupéré le code pour le retravailler.

  3. 03 / VS Code · GitHub Copilot

    Reprise dans VS Code

    J’ai adapté le code dans VS Code avec l’aide de GitHub Copilot. React permet de réutiliser les composants du menu et du pied de page.

  4. 04 / React · Trustindex

    Les avis Google dans React

    Le script Trustindex cherchait son emplacement avant que React ne l’ait créé. J’ai réservé un conteneur et ajusté le lancement du script pour qu’il intervienne après son apparition.

  5. 05 / Netlify

    Déploiement sur Netlify

    Après les tests, j’ai publié le site sur Netlify pour le rendre accessible en ligne.

  6. 06 / React · Netlify

    Résultat final

    Quatre pages présentent le commerce : accueil, histoire, galerie et contact. Le gérant a validé le résultat, comme indiqué dans mon rapport.

Tests réalisés

  • Navigation, liens et boutons.
  • Affichage sur ordinateur et téléphone.
  • Carte de localisation et bouton d’appel.
  • Affichage des avis après correction.
  • Cohérence des pages et validation par le gérant.

Mon bilan

J’ai renforcé mes bases web et découvert le fonctionnement d’une application React. Ce projet m’a appris à organiser mon travail, chercher des solutions et livrer un service utile à un client.

Le problème de Trustindex m’a aidé à comprendre l’importance de l’ordre de chargement des éléments.
